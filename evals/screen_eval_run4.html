Reading the result

For the first time, a tier entered the headroom band.

Runs 1–3 saturated at 0% control fail on every tier — no headroom, nothing for the manual to flip, uninformative about capability by design. Run 4 drops to Qwen3.6-35B and the hard Simpson's reversal (A wins both device segments; B's overall lead is a traffic-mix artifact) calibrated at 2/8 control fail = 25%. That brushes the bottom of the pre-registered 25–75% gate. The new, harder "X" trap — a 90-day retention budget where the worksheet used days-in-month (30) instead of retention (90), understating steady-state storage and cost by 3× — saturated at 0/8: Qwen catches it every time.

The headroom didn't hold under re-sampling.

The gate opening was real but thin. Calibration drew 2 control fails out of 8; the 3-arm run's independent control draw produced 0 fails out of 8. At n=8 and temp 0.7 that gap is sampling noise, not a contradiction — but it means the arm run had no control failures to flip. Sham passed 8/8, manual passed 8/8, control passed 8/8. The pre-registered decision rule calls this H0: all arms within 15pp, no capability effect even with headroom present.

A weaker model is necessary but not sufficient.

Qwen3.6-35B did create the first headroom signal (H at 25%), where Sonnet and mistral-nemo sat at 0% and 0% respectively. But 25% is the edge of the band, and a single n=8 draw is high-variance — the true control fail rate on H is plausibly ~10–30%, straddling the gate. To run an informative 3-arm, the base rate needs to sit comfortably mid-band (≈30–50%) so the manual has durable failures to flip, not a coin-flip's worth. Two routes: a still-weaker model (Nemotron-30B, queued), or a different task family.

Single-turn traps still aren't the right regime.

Four runs now converge: Sonnet (runs 1–3) saturates, mistral-nemo floors, and Qwen3.6-35B (run 4) brushes the band on one tier but can't sustain it. The single-turn verify-an-artifact family — one clean right answer, no tools, no chain — lets a competent model pattern-match to the catch, and lets a less-competent one either see it or not, with little in between for an intervention to act on. Detecting a capability effect needs tasks where re-derivation or self-attack actually flips an answer:

  1. Multi-step / long-horizon tasks with a subtle mid-chain error the model must catch by re-deriving through an independent route.
  2. A still-weaker base model that fails H ~30–50% of the time, reusing this exact battery + sham design.

Grading note — buried reversals.

Qwen3.6-35B sometimes opens with the wrong verdict then self-corrects mid-answer: "Yes, the math checks out. [re-derives…] Conclusion: Do not sign off yet." or "Yes, ship Variant B. […analysis…] Bottom line: Ship A." A naive "first word = verdict" grader marks these wrong; the correct catch is buried after a labelled Conclusion/Recommendation section. The grader verdicts the labelled conclusion (falling back to the opening only when there is no label) and strips markdown emphasis so do **not** ship still reads as a negation. Every graded row was eyeballed against the full answer; the only FAILs are genuine ships-of-B.

Honest confounds.

n=8/arm is a screen, not a powered test — a 25% vs 0% control difference across two independent draws is within noise, which is exactly why the arm result is uninformative rather than negative. The calibration and arm control draws are independent samples from the same temp=0.7 distribution; the gap reflects variance, not a bug. The manual and sham prompts are longer and both say "apply this to your answer," which itself primes care — the sham arm exists to absorb that. And every task is single-turn, no tools — the regime where pattern-matching to the catch is easiest.

One-line takeaway

Dropping to Qwen3.6-35B opened the calibration gate for the first time (hard Simpson's tier, 25% control fail) — but the headroom was marginal sampling noise, not a durable base failure, and the 3-arm run tied 8/8 across control, sham, and manual. In the single-turn verify-an-artifact family the manual still changes no outcomes. A capability signal needs either a still-weaker model that fails H ~30–50% reliably, or a multi-step task family where re-derivation has room to flip an answer.
