A/B Evaluation · Sonnet 5 · 2026-07-07

The manual didn't change what Sonnet caught — only how plainly it showed its work.

Does a reasoning "operating manual" written by Fable 5 change how Opus/Sonnet handle traps? Model held constant, one arm reads the manual, one doesn't. Nine traps built to fire specific failure modes.

Outcome: 9/9 pass, both arms. Every trap was caught with or without the manual — including the authority-pushback follow-up, which both arms held. The manual's measurable effect is on epistemic transparency, not on whether the failure mode fired.

Reading the result

The battery saturates for a capable model.

Sonnet 5 already applies the manual's substance unaided — it challenges the premise, re-derives the number, leads with the bad news, refuses the false attribution, and holds under authority pressure. Single-turn traps with one clean right answer can't separate "has the discipline" from "read the manual," because the discipline is already in the base model.

What the manual reliably changes is the framing.

Every manual-arm answer that could carry a provenance label did — Observed / Derived / Recalled / Assumed appear verbatim — stated its verification as re-derivation by an independent route, and closed with an actionable risk line. Consistent across all nine traps (≈ +1.3 fingerprint points), but a communication-discipline effect, not a capability one.

This is the honest inversion of run 1.

Run 1 compared Opus control against a placebo manual arm (the agents never actually read the file) and couldn't attribute the result. Run 2 holds the model constant and gives the manual arm the real text inline — and lands the same way: the ceiling is the model, not the manual.

To detect a capability effect, the traps must be harder.

Measuring whether the manual changes outcomes needs tasks where the base model sometimes fails — where the "re-derive, don't recognize" or "attack your own conclusion" step actually flips the answer, not just its wording:

  1. Multi-step tasks with a subtle mid-chain error the model must catch by re-deriving.
  2. A long-horizon agentic task where risk-triage changes what gets done first.
  3. A genuinely ambiguous request where mode-classification changes the deliverable itself.

One-line takeaway

With the model held constant, the Fable operating manual made Sonnet 5's answers more epistemically transparent — provenance labels, stated re-derivation, explicit risk — but did not change whether it caught any trap. It's a communication-discipline intervention here, not a capability one.
