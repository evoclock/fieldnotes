What is measured and what is not?

Decode C=1 and C=4 each have one valid cold result per recipe, prompt length and temperature. C=4 is an all-active aggregate, not a per-session rate. Each active-recipe C=4 stream reported zero cached prompt tokens; output counts were reconciled against server usage, not SSE chunks. The retired recipe's long C=4 campaign has more repetitions, so one run per cell is not a confidence interval. Cold 131K and 262K TTFT comes from separate finite C=1 requests. The fresh 500K exact-code checks are under Long-context checks, not decode. The first active-recipe 16K C=4 request cached 14,336 prompt tokens on every stream and is excluded; the uncached retest is used. A dash means inapplicable or unmeasured, never zero.

Metric glossary

Sustained C=1 decode (tok/s)
Complete server-reported output tokens minus the first token, divided by first-to-last streamed output time. Prefill is excluded.
All-active C=4 aggregate decode (tok/s)
Sum of tokenizer-reconciled output rates for four streams during their measured simultaneous active interval (52–86 seconds for the nine accepted active-recipe cells). It is not four individual streams each producing that rate.
First streamed token / TTFT (s)
From request start to the first nonempty streamed reasoning or content delta. Finite long-context and exact-code needle prompts are separate C=1 requests; lower is faster.
Sampling
An omitted temperature field is distinct from explicit temperature 0 or 1. Do not infer one result from another.
